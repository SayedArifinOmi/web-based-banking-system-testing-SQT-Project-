Web-Based Banking System – Software Quality Assurance & Testing

Project Overview

This project focuses on Software Quality Assurance (SQA) and Software Testing for a Web-Based Banking System (iBanking System). It was developed as part of the Software Quality Assurance and Testing course at American International University-Bangladesh (AIUB).

The project involved preparing a comprehensive Software Test Plan, designing and executing test cases, performing functional testing, and conducting browser automation testing using Selenium IDE.

 Project Information:

- Project Name:Web-Based Banking System
- Course:Software Quality Assurance and Testing
- Institution: American International University-Bangladesh (AIUB)
- Test Plan Version:1.0
- Prepared by:S.M. Sayed Arifin Omi
- Supervisor: Abhijit Bhowmik

Testing Scope:

The following modules were covered:

1. User Registration
2. User Login and Authentication
3. Fund Transfer
4. Utility Bill Payment
5. Transaction History
6. Admin Dashboard and Account Management

Testing Activities:

- Software Test Plan preparation
- Requirement analysis (Functional and Non-Functional)
- Test scenario identification
- Test case design and documentation
- Functional test execution
- Positive and negative test scenarios
- Browser automation testing using Selenium IDE
- Database validation
- Defect identification and reporting
- Test execution results and pass/fail analysis

 Tools & Technologies:


- Selenium IDE : Browser automation testing 
- SQL: Database validation 
- Web Browser: Functional testing 
 -Microsoft Word : Test documentation 



Testing Levels:

- Unit Testing
- Integration Testing
- System Testing
- User Acceptance Testing (UAT)

 Non-Functional Testing Considerations:

- Performance
- Reliability
- Security
- Usability
